# Sound effects: where each file comes from

Only sounds with a stated, commercial-use licence belong here (see `references/sound-design.md`).
Add a row for every file you add; a file without a row does not ship.

## Synthesized files

`pop`, `tick`, `ding`, `thud`, `swoosh`, `riser` are generated by `scripts/make_sfx.py` (ffmpeg
oscillators and noise), so they carry no third-party rights. They are not stored here:
`new_remotion_project.py` writes them into a render project's `public/sfx/`.

## Not used, on purpose

Four sounds in `@remotion/sfx` (`bruh`, `windows-xp-error`, `vine-boom`, `ding`) have no author or
licence in Remotion's `generate.ts`, despite a comment calling the group CC0; the first three are
well-known meme or Microsoft sounds. The kit's `ding` is synthesized instead.

## Level and placement

`sfx-map.json` holds the level (`gainDb`) and the lead time of every sound and says which sound
plays on which event.
